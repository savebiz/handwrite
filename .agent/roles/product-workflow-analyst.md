# Specialist Roles Definition Index

## Product Workflow Analyst
- Mission: Define user flows, personas, and product requirements.

## Information Governance Specialist
- Mission: Oversee metadata dictionaries, data retention, and PII guardrails.

## Vision Extraction Specialist
- Mission: Build OCR/Vision extraction agents, crop tools, and confidence scoring.

## Verification QA Specialist
- Mission: Build deterministic rule engine and validation test suite.

## Evaluation Benchmark Specialist
- Mission: Maintain synthetic corpus, gold labels, and scoring scripts.

## Privacy Security Reviewer
- Mission: Audit codebase for secret leaks, PII exposure, and unapproved exports.

## Customer Onboarding Specialist
- Mission: Define and maintain onboarding form schemas and consent logic.

## Hackathon Evidence Editor
- Mission: Create trajectories log, demonstration plan, and changelog updates.
